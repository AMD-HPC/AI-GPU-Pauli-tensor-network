## Key Insights This Session

### 1. Correct wavemap observable: cross-entropy loss

n(v,t) are probabilities (marginals of the Pauli string distribution).
The natural comparison between noisy and noiseless is:

    L(v) = sum_t -ln(n_gamma(v,t) / n_nl(v,t))   in window [t_gamma-Delta, t_gamma+Delta]

- Without n_nl weight: cross-entropy loss (pointwise information loss per site)
- With n_nl weight: KL divergence D_KL(n_nl || n_gamma) contribution at site v

Cross-entropy is the right observable at the frontier because n_nl is tiny there
— the KL weight collapses the signal. Cross-entropy treats all sites equally.

### 2. Delay-adaptive window

Window width = max(1, l_gamma(v)) = max(1, t_gamma - t_nl).
Sites with zero delay get window ±1; sites with large delay get a wide window.
No free parameter — the delay itself sets the window.

### 3. Per-shell entropy loss: the wavefront as information loss peak

The per-shell plot (mean ± sigma of L(v) per BFS distance) reveals:
- Peak position = effective frontier distance for that noise level
- Peak variance = heterogeneity of propagation paths at that shell
- Shell 3: gamma=3 peaks
- Shell 4: gamma=2 peaks  
- Shell 5: MPF peaks (one short of noiseless at shell 6 = 17% residual)
- The MPF reconstructs the frontier delay quantitatively

### 4. Entropy-optimal MPF: two regimes

Frontier MPF minimizes ||F_lr - F_nl||^2 — wrong cost function, discards amplitude.
Entropy MPF minimizes sum_{v,t} -ln(n_MPF/n_nl) subject to LR constraint.

Results:
- Rect 7x7 (information-rich, 49/49 sites): entropy MPF beats best noisy by 27%
  Coefficients [1.32, 0.04, -0.36] — moderate, genuine extrapolation
- Heavy-hex (information-starved, 21/68 sites): LR constraint binding,
  entropy MPF = frontier MPF, 0% improvement

Information cost of causality: gap between unconstrained (mu=-0.69) and
LR-constrained (mu=+2.68) entropy MPF — the price of keeping n_MPF <= n_nl.

### 5. Limitations identified

- MPF independence assumption: noisy states share the same causal paths,
  so they are not independent probes. Maximum entropy requires independent
  variables — violated here because noise enters through the same gate coupling.
- Center dependence: wavemap is a property of lattice + center site, not
  lattice alone. Frontier MPF coefficients will change with center because
  causal path structure changes. Need to show either (a) coefficients are
  center-independent or (b) per-shell distribution is universal.

## Key Physics Discovered This Session

### 1. Noise is pure damping — gate causes all Pauli mixing

Direct eigenvalue analysis of the composed noisy PTMs (from HPP files) shows:

- Off-diagonal power fraction ≈ 36% — constant across all γ=0,1,2,3 (Δ < 0.002)
- Noise channel contributes < 0.1% off-diagonal power
- All Pauli mixing (rotation, sign flips, complex eigenvalues) comes from the gate
- Hardware noise JSON contains near-identity diagonal matrices (eigenvalues 0.997–1.0)

The composed noisy PTM:  G1 · Mn · G2 · Mn · G3 · Mn · G4

is dominated by the gate structure G. Noise only rescales eigenvalue magnitudes.

### 2. γ amplification ≡ rescaling effective Trotter step

Since noise rescales PTM eigenvalues without changing eigenvectors:

  PTM_noisy(γ) ≈ V · (Λ - δΛ(γ)) · V^{-1} ≈ PTM_ideal(ε_eff(γ))

Increasing γ is equivalent to decreasing ε_eff. Extrapolating γ→0 recovers ε_eff→ε.

**Consequence**: γ-MPF and ε-MPF (ergodic amplification) are the same extrapolation
parameterized differently. The L-MPF paper found ε-MPF gives better conditioning
because ε enters PTM eigenvalues directly; γ enters through the composed product,
introducing bond-dependent corrections that break uniformity.

### 3. Correct wavemap observables

Previous session: used cv = std/mean of ratio at noiseless frontier sites.
**This was wrong**: ratio ≈ 0 there because noisy wave hasn't arrived yet.

Correct site-centric observables:
- **Delay**: l_γ(v) = t_γ(v) - t_nl(v)  [first cycle noisy wave crosses threshold, minus noiseless]
- **Natural ratio**: r_γ(v) = n_γ(v, t_γ) / n_nl(v, t_γ)  [both at noisy arrival cycle]

Properties:
- l_γ(v) ≥ 0 always (causality)
- r_γ(v) ≤ 1 always (noiseless always outgrows noisy during the delay)
- No free parameter — t_γ(v) is defined by the data

### 4. Survivorship bias in delay statistics

Mean delay averaged over all reached sites is biased by which sites the noisy
wave fails to reach. Example (rect 7×7):
  N2 reaches 37 sites, μ_l = 1.35
  N3 reaches 25 sites, μ_l = 1.24 (appears "faster")

N3 appears faster only because it gave up on the distant hard sites.
Correct comparison: report (n_reached, μ_l) pair, or per-BFS-shell statistics.

### 5. Frontier definition matters

Old: max-active (max BFS distance where n(v,t) > threshold)
Correct: newly-reached (sites where n(v,t) > threshold AND n(v,t-1) ≤ threshold)

Also: output precision changed from %.4f to %.7f in main_pauli_sweep.cpp
(threshold was at the output floor — all sub-threshold comparisons meaningless)

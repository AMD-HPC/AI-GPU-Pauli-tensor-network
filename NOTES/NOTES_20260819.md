## Message Space: Current State

Two parallel message representations exist:

### messages (chi×chi matrices)
- Allocated for ALL states currently
- Used by: inner product (bilinear_form_bp_gpu*.hpp) — NECESSARY
- Used by: autocorrelation BP warm start — REDUNDANT
- Used by: edge scalar Ze Frobenius dot — REDUNDANT (diagonal = dot(λ_a,λ_b))
- Used by: sqrt_env/inv_sqrt_env absorption — REDUNDANT (Phase 0 fixes this)

### messages_v (chi-vectors, diagonal only)
- Allocated for ALL states
- Used by: bp_update (mode_n_scale path) ✓
- Used by: vertex_scalar_diag ✓
- Used by: bp_converge (extract_diagonal after convergence) ✓
- NOT YET used by: edge scalar Ze, autocorrelation warm start

---

## Agreed Cleanup Plan

**Keep messages (chi×chi) ONLY for inner products.**
All autocorrelation paths migrate to messages_v (chi-vectors).

Benefits:
1. Memory: drop chi×chi from autocorrelation states (~97MB per state at chi=400)
2. Code clarity: autocorrelation_with_bp uses only messages_v
3. Scalar=double: clean single-type path, no mixed buffers
4. Ze: dot(λ_a, λ_b) on chi-vectors — O(chi), exact
5. BP: mode_n_scale only, no fallback, no chi×chi in autocorrelation BP

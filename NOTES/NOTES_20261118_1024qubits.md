## Architecture

- GPU 0: rows 0-15 (17×32 = 544 sites)
- GPU 1: rows 16-31 (17×32 = 544 sites, row 0 = ghost of GPU0 row 16)
- GPU 2: 7×32 boundary slice BP (rows 13-19, 224 sites)
- Normalization: 17/32 (Bethe partition function ratio)
- Split at row 16, boundary bond row15↔row16

## Key properties

- Same physics as 16×32 — same period-6 quincunx seismic works
- Same normalization structure: N_half/N_full = 17/32
- Same 7×32 boundary slice BP (reused from 16×32)
- δlnT detection: normalization cancels in ratio → detection correct
- For absolute n(v,t): multiply by 17/32
